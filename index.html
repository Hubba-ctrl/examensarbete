DevOps Examensarbete

Denna webbserver är deployad automatiskt som en del av mitt examensarbete inom DevOps. Prooojektet körs i en lokal Proxmox-miljö och använder Ansible för automation.

Projektets mål

Målet är att visa hur en enkel webbapplikation kan deployas automatiskt med hjälp av virtualisering, Infrastructure as Code och CI/CD.

Tekniker

  • Proxmox VE för virtualisering
  • Ubuntu Server som virtuell maskin
  • Ansible för konfiguration och deployment
  • GitHub Actions med self-hosted runner för CI/CD
  • Nginx som webbserver
  • Bash-script för teardown och cleanup av virtuella maskiner

Workflow

Nedan visas det enkla flödet för hur deployment fungerar i projektet.

1. Kod ändras lokalt
↓
2. Push till GitHub
↓
3. GitHub Actions triggas
↓
4. Self-hosted runner kör workflow
↓
5. Ansible kör webserver.yaml
↓
6. Nginx och index.html uppdateras på VM
